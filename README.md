# Tools

Small tools I use locally. Each lives in its own folder with setup and usage instructions.

| Tool | What it does | Install |
| --- | --- | --- |
| [Screen Recording Cleaner](screen-recording-cleaner/) | Automatically makes smaller, verified copies of macOS screen recordings in Downloads. Keeps the original resolution and prioritizes picture quality. Exits completely when processing is finished. | Download the repository, then double-click [Install.command](screen-recording-cleaner/Install.command). |
